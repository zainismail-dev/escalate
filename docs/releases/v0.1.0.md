# Escalate v0.1.0

**The AI agent that fights for your refund, so you don't give up.**

Escalate takes a consumer complaint and its evidence and runs it up the escalation ladder,
from the first written demand to a consumer-court filing, drafting every letter and following up
on deadlines. **You approve every message before it is sent.** It runs on your own computer
with a free local model.

## Highlights

- Three case types: **refund refused**, **subscription won't cancel**, **I was scammed** (with
  time-critical steps shown before any letter).
- Works in **any country** through a generic international ladder, with starter packs for
  Pakistan, India, the UK and the US.
- Facts-only drafting: every amount, date and ID is checked against your case before you can
  approve it. Threats and insults are blocked.
- Reminders and deadline warnings that survive restarts; replies are judged automatically
  ("we'll replace it when the claim is approved" counts as a refusal).
- Encrypted evidence, masked personal data, one-click deletion, and a PDF case file for court.
- `$0` to run: Ollama by default; any OpenAI-compatible endpoint works.

## Install

```bash
git clone https://github.com/zainismail-dev/escalate.git && cd escalate
make setup && make up      # open http://localhost:8501
```

## Known limits

- **Not legal advice.** Templates have not yet been reviewed by a lawyer. The India, UK and US
  packs contain `TODO(verify)` items (time limits, authority names, official links).
- **No recommended model yet.** The eval harness is complete, but it has not been run against a
  real model; `make setup` pulls `llama3.1:8b` as a default only.
- Single user, no login: run it on your own machine and don't expose the API to the internet.
- The Urdu interface is partly translated; other UI languages fall back to English.
- Replies are logged by pasting them in; inbox detection comes later.
- Masking of personal data is pattern-based and may miss unusual ID formats.
