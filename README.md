# Escalate

Escalate is an open-source, self-hostable AI agent that runs a consumer complaint (refund
refused, subscription that won't cancel, scam) from the first message to consumer court, using
country "playbooks". It drafts every message, tracks deadlines, follows up and escalates, but
**you approve every outgoing message**. It runs at $0 with a local model via Ollama.

> Work in progress. Not legal advice.
